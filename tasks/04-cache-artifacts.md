# Задание 04. Кэш и артефакты

**Цель:** научиться ускорять пайплайн кэшем и передавать данные между job'ами.

## Шаги

1. Создайте `.github/workflows/artifacts.yml` с **двумя** job'ами:

   **job `build`:**
   - `actions/setup-python@v5` с параметром `cache: pip` и
     `cache-dependency-path: app/requirements.txt`
   - установите зависимости, затем упакуйте код:
     `tar czf app.tar.gz app/ pytest.ini`
   - передайте архив дальше: `actions/upload-artifact@v4`
     (`name: app-package`, `path: app.tar.gz`)

   **job `test`:**
   - `needs: build` — ждёт завершения build
   - **без checkout!** Получите архив: `actions/download-artifact@v4`
     (`name: app-package`)
   - распакуйте и прогните тесты:
     `tar xzf app.tar.gz && pip install -r app/requirements.txt && pytest app/tests -v`

2. Запушьте, откройте запуск. Обратите внимание на граф сверху страницы
   запуска: `build → test` со стрелкой.

3. Прокрутите страницу запуска вниз — там секция **Artifacts** с архивом
   `app-package`, его можно скачать и проверить содержимое.

4. Запушьте ещё раз (можно пустой коммит: `git commit --allow-empty -m "rerun"`)
   и сравните время шага установки зависимостей в job `build` — со второго
   раза pip должен отработать заметно быстрее благодаря кэшу.

## Критерий выполнения

- Запуск содержит два job'а, связанные стрелкой `build → test`
- Внизу страницы запуска есть скачиваемый артефакт
- Job `test` проходит БЕЗ шага checkout — код приходит из артефакта
- Второй запуск быстрее первого (покажите разницу по времени шага install)
